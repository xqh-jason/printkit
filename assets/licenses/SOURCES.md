# License text sources

The `*.txt` files listed in the table below are verbatim copies of the
canonical texts from the
[SPDX license-list-data](https://github.com/spdx/license-list-data)
repository, release **v3.29.0** (published 2026-09-16), retrieved on
2026-11-12. `scripts/gen-notices.py` verifies every listed file against the
SHA-256 values before generating the notices. `component-licenses.txt` is the
generated per-component appendix, not an SPDX text.

SPDX publishes MIT, BSD and ISC as license *templates*. Fields such as
`<year>`, `<owner>` and `<copyright holders>` are intentionally left as
placeholders here; the holder for each component is in
`THIRD-PARTY-NOTICES.md` and the full per-component text is in
`component-licenses.txt` (this directory).
